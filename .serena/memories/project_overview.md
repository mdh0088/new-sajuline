# 사주라인 리뉴얼 프로젝트 개요

## 프로젝트 목적
기존 sajuline.com 플랫폼의 UI/UX 현대화 및 모바일 최적화를 통한 AI와 전문가의 하이브리드 사주 상담 서비스 제공

## 핵심 목표
- 기존 노후화된 UI/UX 현대화
- 모바일 퍼스트 환경 최적화
- AI 기술 도입으로 서비스 차별화
- 사용자 여정 단순화 및 전환율 향상

## 타겟 사용자
- 연령: 25-55세 성인
- 성별: 여성 65%, 남성 35%
- 디지털 네이티브, 모바일 활용도가 높은 사용자층

## 주요 기능
1. **AI 운세 서비스**: 3초 내 즉시 사주 분석, 개인화된 일/주/월 운세
2. **전문 상담사 매칭**: 스마트 추천 및 실시간 예약 시스템
3. **실시간 채팅 상담**: WebSocket 기반 즉시 상담
4. **포인트 시스템**: 투명한 요금제, 다양한 충전 옵션
5. **커뮤니티 기능**: 후기, Q&A, 상담사 랭킹

## 차별화 포인트
- AI + 전문가 하이브리드 모델
- 투명하고 합리적인 요금제
- 모던 UX/UI
- 검증된 상담사와 신뢰성 시스템

## 개발 단계
- Phase 1: Core MVP (4주)
- Phase 2: Enhanced Features (8주)  
- Phase 3: Scaling & Optimization (4주)
- Phase 4: Scale & Optimize (8주)
