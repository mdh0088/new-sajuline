# 사주라인 폰트 시스템 적용 완료

## 📊 변경 사항

### 1. CSS 변수 시스템 도입
- `main.css`에 전역 폰트 크기 변수 정의
- 일관된 폰트 크기 관리

### 2. 통일된 타이포그래피
- `typography.css` 생성 및 자동 적용
- 모든 페이지에 일관된 폰트 크기 적용

### 3. 폰트 크기 가이드라인

#### 작은 화면 (400px 이하)

**타이틀**
- Display: 22px (메인 타이틀)
- H1: 20px (페이지 타이틀)
- H2: 18px (섹션 타이틀)
- H3: 16px (서브 타이틀)
- H4: 15px (작은 타이틀)
- H5: 14px (미니 타이틀)

**본문**
- Body Large: 14px (버튼, 입력 필드)
- Body: 13px (기본 본문)
- Body Small: 12px (보조 정보)
- Caption: 11px (최소 크기)

## 🎯 핵심 원칙

1. **최소 11px**: 가독성 확보
2. **기본 12-13px**: 본문 텍스트
3. **타이틀 18-22px**: 계층 구조 유지
4. **자동 적용**: CSS 변수 + typography.css

## 📝 사용 방법

### CSS에서
```css
.my-title {
    font-size: var(--font-size-h2);
}
```

### 클래스 사용
```html
<h2 class="section-title">섹션 제목</h2>
<p class="description-text">설명 텍스트</p>
```
