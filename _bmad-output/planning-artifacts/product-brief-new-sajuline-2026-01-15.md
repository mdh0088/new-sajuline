# Product Brief: new-sajuline

## Executive Summary

**new-sajuline**은 기존 sajuline.com을 현대화한 AI 기반 하이브리드 사주 상담 플랫폼이다.
올드한 UI와 느린 서비스로 인한 사용자 이탈 문제를 해결하고, AI 운세 서비스를 통해
사주에 관심 있는 모든 사용자에게 간편하고 트렌디한 경험을 제공한다.

**핵심 가치 제안:**
- AI 기반 일일/주간 운세로 낮은 진입장벽 제공
- 모던하고 빠른 모바일 퍼스트 UX
- 포인트 기반 투명한 결제 시스템 (신규 가입 시 10,000P 지급)
- 전문 상담사와 AI의 하이브리드 상담 모델

---

## Core Vision

### Problem Statement

사주 상담에 관심 있는 사용자들은 기존 서비스의 **올드한 UI**, **느린 서비스 속도**,
**더딘 업데이트**로 인해 만족스러운 경험을 얻지 못하고 있다.
특히 AI 시대에 발맞춘 현대적인 사주 서비스가 부재한 상황이다.

### Problem Impact

- 사용자 이탈 및 신규 가입 저조
- 젊은 세대의 사주 서비스 접근성 저하
- 경쟁 서비스 대비 기술적 뒤처짐
- 시장 선점 기회 상실 위험

### Why Existing Solutions Fall Short

| 기존 솔루션 | 한계점 |
|-------------|--------|
| 기존 sajuline.com | 올드한 디자인, 느린 서비스, 업데이트 지연 |
| 타 사주 앱 (점신 등) | AI 특화 서비스 부재, 차별화된 경험 부족 |
| 오프라인 상담 | 접근성 낮음, 시간/비용 부담 |

### Proposed Solution

**new-sajuline**은 다음과 같은 단계적 접근으로 문제를 해결한다:

**Phase 1 (MVP):**
- AI 기반 일일/주간/월간/연간 운세 서비스
- 모던 UI/UX 리뉴얼 (완료)

**Phase 2 (확장):**
- 전문 상담사 실시간 채팅 상담
- AI + 전문가 하이브리드 모델

**Phase 3 (진화):**
- 전문 상담사가 사주 데이터 제공
- AI가 데이터 기반 상담 서비스 수행

### Key Differentiators

| 차별점 | 설명 |
|--------|------|
| **AI 선점** | 명확한 AI 사주 서비스 리더가 없는 시장에서 선점 기회 |
| **개발 민첩성** | 1인 개발자의 빠른 개발-테스트-적용 사이클 |
| **하이브리드 모델** | AI와 전문 상담사의 시너지 (점진적 AI 전환) |
| **트렌디한 UX** | AI 시대에 맞는 현대적이고 빠른 서비스 경험 |
| **낮은 진입장벽** | 10,000P 무료 제공으로 약 5분 체험 가능 |

## Target Users

### Primary Users

#### 메인 페르소나: "민지" (30대 여성 헤비 유저)

| 항목 | 내용 |
|------|------|
| **프로필** | 34세, 직장인 여성, 기혼 |
| **상황** | 이직, 출산 등 인생의 중요한 결정을 앞두고 있음 |
| **이용 패턴** | 월 1-2회 정기 상담, 중요 결정 시 반드시 확인 |
| **니즈** | 신뢰할 수 있는 사주 상담으로 불확실한 미래에 대한 지침 얻기 |
| **Pain Point** | 기존 서비스의 올드한 UI, 느린 속도에 불만 |

#### 서브 페르소나별 특성

| 연령대 | 주요 관심사 | 이용 빈도 |
|--------|-------------|-----------|
| **20대** | 취업운, 연애운 | 가끔 (호기심/특정 이벤트 시) |
| **30~40대** | 커리어, 결혼, 인생 방향 | 정기적 (헤비 유저 다수) |
| **50대 이상** | 자녀 진로, 부모 건강, 가족 문제 | 정기적 |

**핵심 타겟**: 30대 이상 여성, 중요한 결정 앞에서 전문 상담을 받는 장기 이용 헤비 유저

### Secondary Users

#### 상담사 (약 100명)
- **역할**: 전문 사주 상담 제공
- **중요성**: 서비스 만족도의 핵심 요소 (상담사 역량 = 사용자 만족도)
- **니즈**: 효율적인 상담 관리, 고객과의 원활한 소통 도구

#### 관리자 (3명)

| 역할 | 인원 | 담당 업무 |
|------|------|-----------|
| 개발/총괄 관리자 | 1명 | 개발, 전체 서비스 관리 |
| 운영 관리자 | 2명 | 일상 사이트 운영, 고객 지원 |

### User Journey

#### 신규 사용자 여정

| 단계 | 행동 | 핵심 포인트 |
|------|------|-------------|
| **발견** | 네이버 광고 클릭 | 현재 주요 유입 채널 |
| **가입** | 회원가입 (이메일/SNS) + 본인인증 | 핸드폰 번호 기준 10,000P 지급 (중복 불가) |
| **첫 경험** | 무료 포인트로 약 5분 상담 체험 | 진입장벽 낮춤 |
| **가치 인식** | 사주가 잘 맞는 경험 | 상담사 역량이 핵심 |
| **전환** | 포인트 충전 → 유료 상담 | 만족 시 결제 전환 |
| **충성** | 정기 상담 + 중요 결정 시 이용 | 헤비 유저화 |

#### 핵심 성공 지표
- **가치 인식 순간**: 상담사의 사주 해석이 본인 상황과 잘 맞아떨어질 때
- **재방문 동기**: 신뢰할 수 있는 상담사 발견 → 지속적 관계 형성

## Success Metrics

### 핵심 성공 기준

현재 단계에서는 매출보다 **서비스 안정성**과 **지속적인 개발**에 집중한다.

| 우선순위 | 성공 기준 |
|----------|-----------|
| 1순위 | 서비스가 안정적으로 운영됨 |
| 2순위 | 빠른 개발-테스트-배포 사이클 유지 |
| 3순위 | 사용자 경험 개선 (UI/UX, 속도) |

### 기술 성능 지표 (KPI)

| 지표 | 목표 | 측정 방법 |
|------|------|-----------|
| API 응답시간 | p95 < 300ms | 서버 모니터링 |
| AI 운세 응답시간 | < 3초 | OpenAI API 응답 추적 |
| 페이지 로드 (LCP) | < 2.5초 | Core Web Vitals |
| 서비스 가용성 | 99%+ | 업타임 모니터링 |

### 사용자 경험 지표

| 지표 | 의미 |
|------|------|
| 첫 상담 완료율 | 신규 가입 → 첫 상담 전환 |
| 재방문율 | 서비스 만족도 간접 측정 |
| AI 운세 이용률 | 새 기능 채택도 |

### 개발 목표

| 목표 | 설명 |
|------|------|
| 빠른 이터레이션 | 1인 개발자 강점 활용, 빠른 피드백 반영 |
| AI 기능 확장 | Phase 1(일일/주간 운세) → Phase 2(하이브리드) → Phase 3(AI 상담) |
| 기술 부채 최소화 | 리뉴얼 시 클린 아키텍처 유지 |

## MVP Scope

### Core Features

#### AI 운세 서비스 (MVP 핵심)

| 기능 | 설명 | 우선순위 |
|------|------|----------|
| **일일 운세** | 오늘의 운세 AI 분석 | P0 (필수) |
| **주간 운세** | 이번 주 운세 AI 분석 | P0 (필수) |
| **월간 운세** | 이번 달 운세 AI 분석 | P0 (필수) |
| **연간 운세** | 올해 운세 AI 분석 | P0 (필수) |

**기술 구현:**
- OpenAI API 연동
- 사용자 사주 정보 기반 (생년월일, 태어난 시간)
- 프롬프트 템플릿 방식 (일일/주간/월간/연간 차이는 프롬프트 변경)
- 로그인 필수 (가입 시 입력한 사주 정보 활용)
- 추가 사용자 입력 없음 (기존 데이터 활용)

**이미 완료된 기능:**
- 모던 UI/UX 리뉴얼 ✅
- 기존 상담 서비스 (상담사 목록, 예약, 채팅) ✅
- 회원 시스템 (가입, 로그인, 소셜 로그인) ✅
- 결제 시스템 (포인트 충전) ✅
- 관리자 시스템 ✅

### Out of Scope for MVP

| 기능 | 이유 | 향후 계획 |
|------|------|-----------|
| AI 채팅 상담 | Phase 2 범위 | 전문 상담사 데이터 기반 구현 |
| 상담사 AI 어시스턴트 | Phase 3 범위 | 상담사가 데이터 제공 → AI 상담 |
| 궁합 분석 | 추가 개발 필요 | 운세 안정화 후 검토 |
| 타로/꿈해몽 | 다른 도메인 | 장기 검토 |

### MVP Success Criteria

| 지표 | 목표 | 측정 방법 |
|------|------|-----------|
| AI 운세 응답시간 | < 3초 | API 응답 모니터링 |
| AI 운세 이용률 | 가입자의 30%+ | 일일 운세 조회 수 |
| 서비스 안정성 | 99%+ 가용성 | 업타임 모니터링 |
| 사용자 피드백 | 긍정적 반응 | 정성적 피드백 수집 |

### Future Vision

**Phase 2: 하이브리드 상담**
- 전문 상담사 + AI 보조 상담
- AI가 사전 분석 제공 → 상담사가 심층 상담

**Phase 3: AI 중심 상담**
- 상담사가 사주 데이터/해석 패턴 제공
- AI가 데이터 기반 자동 상담 수행
- 상담사는 복잡한 케이스만 담당

**장기 비전:**
- AI 사주 서비스 시장 선점
- 개인화된 운세 알림 서비스
- 사주 기반 라이프스타일 추천
