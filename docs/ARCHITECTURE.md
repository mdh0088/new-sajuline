# 사주라인 시스템 아키텍처

## 개요

사주라인은 AI와 전문가의 하이브리드 사주 상담 플랫폼으로, 4개의 독립적인 애플리케이션으로 구성된 모노레포 구조입니다.

## 애플리케이션 구조

### 1. Frontend (사용자 웹)
- **기술**: Nuxt 4 + Vue 3 + TypeScript
- **역할**: SSR 기반 사용자 서비스
- **포트**: 3100 (Production)
- **주요 기능**: 운세 서비스, 상담 예약, 포인트 충전

### 2. Admin-Frontend (관리자 웹)
- **기술**: Vue 3 + Vite 5 + TypeScript
- **역할**: SPA 기반 관리자 대시보드
- **포트**: 3300 (Production)
- **주요 기능**: 회원/상담사 관리, 결제 관리, 통계

### 3. Backend (사용자 API)
- **기술**: FastAPI + Python 3.11
- **역할**: 사용자 서비스 API
- **포트**: 8000
- **주요 기능**: 인증, 운세 AI, 채팅, 결제

### 4. Admin-Backend (관리자 API)
- **기술**: FastAPI + Python 3.11
- **역할**: 관리자 서비스 API
- **포트**: 8001
- **주요 기능**: 대시보드, 회원 관리, 통계

## 데이터 흐름

### 사용자 요청 흐름
```
사용자 → CloudFront → Route53 → ALB → Nginx → Nuxt(SSR) → Backend API → MariaDB
                                                    ↓
                                              Redis (세션/캐시)
```

### 관리자 요청 흐름
```
관리자 → CloudFront → Route53 → ALB → Nginx → Static Files
                                         ↓
                              Admin-Backend API → MariaDB/MSSQL
```

### 이미지 처리 흐름
```
이미지 업로드 → S3 → Lambda (리사이징) → CloudFront (CDN 배포)
```

## 보안 아키텍처

### 네트워크 보안
- **VPC 격리**: Public/Private 서브넷 분리
- **Bastion Host**: SSH 점프 서버로 직접 접근 차단
- **Security Groups**: 최소 권한 원칙 적용

### 애플리케이션 보안
- **JWT 인증**: HttpOnly 쿠키 + CSRF 토큰
- **Rate Limiting**: API 요청 제한 (60req/min)
- **SQL Injection 방어**: Nginx 레벨 필터링
- **XSS 방어**: CSP 헤더 설정

### 데이터 보안
- **전송 암호화**: TLS 1.2+
- **저장 암호화**: AES-256-GCM (민감 정보)
- **비밀번호**: Argon2id 해싱

## 확장성 고려사항

### 현재 구성
- **Auto Scaling**: EC2 인스턴스 수평 확장 가능
- **이중화**: 다중 AZ 구성 준비됨
- **캐싱**: Redis를 통한 세션/데이터 캐싱

### 향후 확장
- **컨테이너화**: Docker/ECS 마이그레이션 고려
- **마이크로서비스**: 도메인별 서비스 분리 가능
- **CDN 최적화**: 정적 자산 캐싱 전략 개선

## 모니터링 및 로깅

### 에러 추적
- **Sentry**: 실시간 에러 모니터링 및 알림

### 로깅
- **구조화 로깅**: JSON 형식, 요청 ID 상관관계
- **로그 레벨**: DEBUG/INFO/WARNING/ERROR

### 성능 모니터링
- **Google Analytics 4**: 사용자 행동 분석
- **Core Web Vitals**: LCP, FID, CLS 추적
