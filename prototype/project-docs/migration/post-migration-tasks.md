# 마이그레이션 후 작업 목록

## 개요
데이터베이스 마이그레이션 완료 후 필요한 작업들을 정리한 문서입니다.

## 1. 즉시 처리 필요 작업 (Critical)

### 1.1 보안 관련
- [ ] **비밀번호 해시 적용**
  - 모든 평문 비밀번호를 bcrypt로 해시
  - 관리자 계정 우선 처리
  - 상담사 계정 처리
  - 사용자 계정 일괄 처리

- [ ] **외부 MSSQL 연동 점검**
  - 포인트 차감 API 연동 테스트
  - 동기화 배치 작업 설정
  - 실패 시 재시도 로직 확인

### 1.2 데이터 정합성
- [ ] **외래키 제약조건 활성화**
  ```sql
  SET FOREIGN_KEY_CHECKS = 1;
  ```

- [ ] **고아 레코드 처리**
  - 참조 무결성 위반 데이터 정리
  - 삭제된 사용자의 관련 데이터 익명화

- [ ] **서비스 로직 수정**
  - 트랜잭션 범위 재검토

  - 불필요한 인덱스 제거

- [ ] **쿼리 최적화**

  - 캐싱 전략 수립
